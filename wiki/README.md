# PhotoPainter 应用框架开发者 Wiki

从 **[Wiki 首页与阅读路线](Home.md)** 开始。

这份 Wiki 是应用开发规范的统一入口，源码随 `esp32s3` 仓库版本管理。它描述 ESP-IDF/FreeRTOS 上的常驻宿主、独立 ELF 应用、宿主服务和通信协议。接口细节以对应版本的 SDK、校验器和协议实现为准。

当前文档基线：2026-10-23。宿主支持 ABI 1 / 2.0 / 2.1；**APP 自行通过 BLE 收图已在 Mac 本地功能分支实现，部分实测通过；最终验收与代码推送尚未完成**。已验证的宿主专用 PNG 通道保留作兼容基线，不作为新应用的开发方向。

GitHub 原生 Wiki 尚未初始化；本目录是已发布、可审查的正式文档入口，不依赖原生 Wiki 页签。未来若启用原生 Wiki，应从本目录同步，避免两份规范分叉。
