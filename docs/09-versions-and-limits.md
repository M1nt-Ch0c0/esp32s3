# 版本与已知限制

这一页说明各组件当前的版本、它们之间的兼容关系、不同客户端平台支持哪些能力，以及设计上的已知限制和后续计划。其他页面讲原理和用法；版本和限制集中在这里，方便统一更新。

## 组件版本

| 组件 | 当前版本 | 说明 |
|---|---|---|
| 宿主固件（photopainter-host） | 应用 ABI 2.3，配对 v2 | 通过 USB 更新 |
| 相框应用（photoframe） | v21，声明 ABI 2.3 | 通过蓝牙安装 |
| 电脑端（ai-quota-frame） | `main` 分支 | 命令行和常驻后台 |
| CPM 网页插件 | 0.3.3 | CPA 插件，页面在访问者的浏览器里运行 |
| macOS 控制台（photopainter-console） | 0.4.1 | 需要 Apple Silicon、macOS 14 以上 |

## 兼容关系

- **宿主与应用**：宿主只加载 ABI 次版本不高于自己的应用。要用新 ABI 的应用，先升级宿主。规则见[应用接口参考](05-app-api-reference.md)。
- **配对**：宿主只接受配对 v2。HTTP 控制接口不可用，只保留 `/health` 用于确认设备在线。
- **传图速度**取决于相框应用和客户端共同支持的传输方式：

| 相框应用 | 网页插件 | Mac 原生客户端 | Windows / Linux 原生客户端 |
|---|---|---|---|
| ABI 2.3（v21 起） | GATT 大消息，66 KiB 约 8 秒 | CoC，约 25 KiB/s | GATT 小消息，一张图需要几分钟 |
| ABI 2.2 | GATT 小消息，66 KiB 约 4–5 分钟 | CoC，约 25 KiB/s | GATT 小消息，一张图需要几分钟 |

## 各客户端支持的功能

| 功能 | 网页插件 | Mac 后台 + 控制台 | Windows / Linux 命令行 |
|---|---|---|---|
| 配对、读状态 | 支持 | 支持 | 支持 |
| 推图 | GATT 大消息 | CoC，不可用时 GATT 小消息 | GATT 小消息 |
| 定时自动推送 | 页面在前台时 | 常驻后台 | 常驻后台 |
| 安装、激活、切换、回滚、删除应用 | 开发者工具 | 控制台、命令行 | 命令行 |
| 图片事务身份持久化 | 支持（IndexedDB） | 仅进程内存 | 仅进程内存 |
| USB 维护（备份、刷宿主） | 不支持 | 控制台、`usb-maintenance.py` | `usb-maintenance.py` |

## 已知限制

1. **启动保护不区分复位原因。** 应用启动窗口内的任何复位，包括断电和按电源键，都会被当成启动失败，触发一次回退；没有可回退槽时会停在故障空闲。详见[启动保护](03-how-the-device-works.md#启动保护)。
2. **没有“激活指定槽”的命令。** 可回退槽为空时，要用另一个槽里的版本只能重新上传再激活。开始上传时宿主会先清空可回退槽。
3. **原生客户端不支持 GATT 大消息。** Windows、Linux 以及无法打开 CoC 的 Mac 只能走每块约 100 字节的旧接口。
4. **原生客户端的图片事务身份不持久。** 后台进程重启后无法再查询上一次未确认的图片结果，只能人工核对屏幕。
5. **网页定时推送依赖页面在前台。** 锁屏、切换应用或关闭页面后暂停，回到页面后继续，错过的轮次不补发。
6. **没有电源遥测。** 固件不上报电池电压和电源芯片的关机原因，供电问题只能通过复位原因间接判断。
7. **图片回执只保存在内存里。** 相框重启后，重启前的图片结果无法查询。

## 后续计划

- 启动保护只把崩溃、看门狗等真正的失败计入，并在连续多次失败后才回退。
- 宿主增加“激活指定槽”命令。
- 原生 Go 客户端支持 ABI 2.3 大消息，并持久化图片事务身份。
- Windows 原生客户端支持 CoC。
- 统一消息协议，见[提案](proposals/unified-message-protocol.md)。
